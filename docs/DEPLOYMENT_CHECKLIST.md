# Portfolio Deployment Checklist

Use this checklist before promoting a portfolio build.

## Content

- Featured projects link to the correct repositories or live products.
- Contact and social links open the intended destination.
- Availability/status copy is current.
- No placeholder text remains.

## Technical

- Production build completes successfully.
- No secrets are exposed in client bundles or committed files.
- Navigation works on direct page loads.
- Images and fonts load without broken requests.
- Metadata, page title, and social preview information are valid.

## Experience

- Test desktop and mobile layouts.
- Check keyboard navigation and visible focus states.
- Verify reduced-motion behavior where supported.
- Confirm animations do not hide important content.
- Test the primary contact/recruiter journey from landing page to action.

## After deploy

Open the production URL in a clean session and verify the most important routes rather than relying only on the deployment status.
