# Nityansh Rupesh Bahadur — Portfolio

A personal portfolio and digital CV focused on full-stack development, Python, AI, product thinking, and interactive frontend work.

**Live:** https://nityansh-portfolio.vercel.app

## What visitors can explore

- Selected projects and case studies
- About, experience, and technical focus
- CV with print/PDF support
- Recruiter-oriented portfolio terminal
- Contact and availability information

## Tech stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- Next.js App Router

## Project structure

```text
app/            Routes, layouts, pages, and page-level content
components/     Reusable UI and interactive sections
lib/            Shared helpers and project utilities
public/         Static assets
ARCHITECTURE.md Technical structure and implementation notes
```

## Run locally

```bash
npm install
npm run dev
```

Then open the local Next.js development URL shown in the terminal.

## Verify before deployment

```bash
npm run lint
npm run build
```

## Design direction

The portfolio is intentionally built as a polished product rather than a static resume page. The design prioritizes:

- Clear content hierarchy
- Smooth cinematic interaction without blocking usability
- Strong mobile responsiveness
- Focused project storytelling
- Fast access to recruiter-relevant information
