# Nityansh Rupesh Bahadur — Portfolio

Personal portfolio for Nityansh Rupesh Bahadur, a Full Stack Developer from Lucknow exploring Python and AI.

## Stack

- Next.js 14 + React 18 + TypeScript
- Tailwind CSS
- Framer Motion
- Next App Router

## Sections

- Work and project case studies
- About and experience
- CV with print / PDF support
- Portfolio terminal for recruiter questions
- Contact

## Run locally

```bash
npm install
npm run dev
```

Production verification:

```bash
npm run lint
npm run build
```
